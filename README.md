One line about office life, under 200 characters: the printer jams on page
one of a resignation letter, HR prints it — and staples a counter-offer to
the back. A three-beat escalation: the jam, the helpful print, the twist.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt`.
